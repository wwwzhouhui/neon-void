## 验证及限制

通过 `node --experimental-loader ./tests/three-loader.mjs tests/gameplay.mjs`：冲刺方向、冷却、死亡禁用、重置、掩体阻挡；换弹进度、完成及切枪取消。

通过 `MAKEFUN_OUTPUT_DIR=<临时目录> node main.ts`：原版 kit 未修改，dossier 正常生成；text 字段约74KB，低于160KiB（总JSON包含base64图片，不能拿总文件大小和文本上限比较）。`git diff --check` 通过。

本环境 Chromium 因操作系统 socket 权限拒绝而未能启动，浏览器交互、WebGL实际渲染和缩图可读性尚未验证。screenshots/ 仍为v1原图，不能作为本次新增机制的截图证明。参赛前必须重新试玩并截取真实画面；不要将旧图随新代码直接视为完整新提交。

## 最终参赛前必做

1. 在支持原始会话导出及真实模型用量记录的构建环境保留本次全部修改记录；此仓库提交不包含可验证的完整会话 bundle，本对话不能伪造 provider usage。
2. 与v1构建会话一起重新打包，核对 run record、provider/model、用量记录和父子会话完整性。官方在11月17日00:00 UTC起加强相关检查，不应假定v1通过即代表新版本通过。
3. 实际浏览器验证开始→战斗→清波→死亡→重开，以及暂停/恢复、冲刺与连杀；重新生成3–4张截图。标题、HUD战斗、结算重开必须可辨识，单张≤256KiB。
4. 用原kit重算dossier并执行完整check，核对有效性、来源门槛、README徽章/referral和About，不改owner与freshness证明。
5. 用新commit和完整bundle签名提交，并检查服务端状态。GitHub push不等于make.fun提交；本轮未执行比赛提交、未消耗比赛提交额度。
